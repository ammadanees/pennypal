================================================================================
2. DIRECT APK INSTALLATION INSTRUCTIONS (ON ANDROID DEVICE)
================================================================================
Method A: Direct USB / File Transfer
  1. Copy 'app-arm64-v8a-release.apk' to your Android phone (via USB cable, 
     Google Drive, WhatsApp, or email).
  2. Open the 'Files' or 'File Manager' app on your Android device.
  3. Tap on 'app-arm64-v8a-release.apk'.
  4. If prompted with "Install unknown apps" or "Security warning", enable 
     "Allow from this source" in Device Settings.
  5. Tap 'Install'.
  6. Tap 'Open' to launch PennyPal.

Method B: Android Debug Bridge (ADB) via Terminal
  If you have an Android device connected with USB debugging enabled:
  ```bash
  adb install -r build/app/outputs/flutter-apk/app-arm64-v8a-release.apk
  ```

3. DEVELOPER INSTALLATION & SOURCE CODE SETUP (MANDATORY)
================================================================================

3.1 System Prerequisites:
  - Operating System: Windows 10/11, macOS (Sonoma/Sequoia), or Ubuntu Linux 22.04+
  - Flutter SDK: Version 3.24.0 or higher
  - Dart SDK: Version 3.5.0 or higher
  - Java Development Kit (JDK): Version 17 (Required for Gradle 8+)
  - Android Studio / SDK: Android SDK Platform 34, Android Build-Tools 34.0.0

3.2 Step-by-Step Installation:
  1. Clone or extract the project directory:
     ```bash
     git clone https://github.com/ammadanees/pennypal.git
     cd pennypal
     ```

  2. Install Flutter Dependencies:
     ```bash
     flutter pub get
     ```

  3. Validate Codebase Health & Run Tests:
     ```bash
     flutter analyze
     flutter test
     ```
     (All 73 unit and widget tests will pass)

  4. Launch the Application in Development Mode:
     - For Web (Chrome):
       ```bash
       flutter run -d chrome
       ```
     - For Connected Android Device or Emulator:
       ```bash
       flutter run -d android
       ```

  5. Compile Production Android Package File (Release APK):
     ```bash
     flutter build apk --split-per-abi
     ```
     The generated release packages will be located at:
     build/app/outputs/flutter-apk/app-arm64-v8a-release.apk
