# PennyPal — Speaker Cheat Sheet: Words & Short Sentences

> **How to use this guide:**  
> - **Don't memorize long paragraphs.**  
> - Look at the **🔑 Essential Words** to get the right word in your head.  
> - Speak the **🗣️ Small Sentences** (only 5 to 8 words each).  
> - Follow the **👉 Action** with your hands on screen.

---

## 🧭 Handy Bridge Words (To Switch Screens Smoothly)

When you finish one screen and want to move to the next screen, use any of these simple words:

| Word / Phrase | When to use it | Example |
| :--- | :--- | :--- |
| **"Now, let's look at..."** | Moving to a new screen | *"Now, let's look at the budget screen."* |
| **"Next, watch this..."** | Showing an interesting action | *"Next, watch this: I turn on Airplane Mode."* |
| **"Right here, you can see..."** | Pointing with your mouse | *"Right here, you can see three cards."* |
| **"For example..."** | Explaining a real situation | *"For example, buying lunch at campus."* |
| **"And what's really good is..."** | Highlighting a great feature | *"And what's really good is it works offline."* |
| **"Basically..."** | Explaining in simple words | *"Basically, it stops students from overspending."* |

---

## 🆘 Rescue Words (If Your Mind Goes Blank)

If you freeze or forget a word, **do not worry or panic**. Take a breath and use these safe phrases:

- *"Let me show you this on screen."* (Buys you 3 seconds while you tap).
- *"In simple words..."* (Lets you reset your sentence).
- *"What this means is..."* (Helps you explain simply).
- *"My teammate worked on this part, so he can explain details."* (Passes to teammate).

## Section 15: Quick 1-Line Answers for Judge Questions

If a judge asks a question, **don't give a long speech**. Give one or two short sentences:

| Question | 🗣️ What to say (Short & Simple) |
| :--- | :--- |
| **Q1. Why Riverpod instead of Provider?** | *"Riverpod is safe at compile time. It never crashes with ProviderNotFound."* |
| **Q2. How does offline mode work?** | *"Firestore stores data on the phone first. When internet returns, it syncs to cloud."* |
| **Q3. Why allow only 2 cards?** | *"To keep things simple and stop students from overspending on multiple cards."* |
| **Q4. What if Gemini API fails?** | *"We have a local backup engine that reads receipt text without internet."* |
| **Q5. How is user data secure?** | *"Each user has their own Firebase folder. No student can see another student's data."* |
| **Q6. What happens if month ends?** | *"All-time balance carries forward. Monthly expenses reset to zero for the new month."* |
| **Q7. How did you test the app?** | *"We wrote 73 automated tests for all math formulas and tested manual offline mode."* |
| **Q8. What if user spends more than budget?** | *"The ring turns red, health score drops, and the app alerts the student immediately."* |
| **Q9. Can it work on web and desktop?** | *"Yes, Flutter builds for mobile, web, and desktop from this one codebase."* |
| **Q10. What is your future plan?** | *"We want to connect university meal cards and add local bank notifications."* |

## Section 16: 1-Line Tech Stack Cheatsheet (Tools & Technologies Used)

If judges ask: *"What tools did you use and why?"*, use these simple 1-line answers:

- **Flutter:** *"Builds our app for mobile, tablet, and web from a single codebase."*
- **Firebase Auth:** *"Manages secure student login, signups, and password resets."*
- **Cloud Firestore:** *"Our cloud database that automatically caches data for offline use."*
- **Cloudinary:** *"Stores and optimizes paper receipt photos and profile pictures in the cloud."*
- **Brevo (Sendinblue):** *"Sends automated email verification links and budget alerts."*
- **Google Gemini AI:** *"Scans receipts to extract amounts and answers budgeting questions."*
- **Riverpod 2.0:** *"Manages app data reactively without unnecessary screen rebuilds."*
- **GoRouter:** *"Protects application routes and separates student screens from the admin panel."*
- **SharedPreferences:** *"Saves user settings like dark mode and default currency on the phone."*
- **Flutter Local Notifications:** *"Triggers instant phone notifications when spending reaches 80% or 100% of budget."*
- **Pdf & Printing Package:** *"Generates and prints formatted monthly student spending reports."*
- **GitHub:** *"Used by our team for version control, code branches, and collaboration."*
